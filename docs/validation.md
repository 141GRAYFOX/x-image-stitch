# 验证说明

验证日期：2026-10-22。

## 已完成

在独立的 Chrome for Testing 151 / Chromium 测试环境中，真实加载本目录的 Manifest V3 扩展。
X 网页结构和图片响应使用本地模拟数据，四张图片各为 240 × 180 像素，并使用不同颜色标记。

v1.3.0 旋转版的 22 项浏览器端检查通过：

1. 扩展加载及后台 Service Worker 启动。
2. 2～4 图推文识别、单图排除、引用推文图片隔离；图片链接已出现但图片尚未完整加载时不提供不完整拼图。
3. 在当前网页内显示唯一浮窗，页面限制 `frame-src 'self'` 时仍能正常嵌入扩展预览，浏览器标签页数不变。
4. 默认横向无缝拼接，四张图片从左到右的像素颜色及位置正确。
5. 交换图片顺序及还原后，合成像素符合预期。
6. 竖拼、两列网格、横拼的原始像素尺寸正确。
7. 原始大小与适应窗口操作正常。
8. 浮窗内 PNG 实际下载成功，文件头尺寸为 960 × 180 像素。
9. 右上角关闭按钮移除浮窗，恢复原页面滚动样式及优先级，并将键盘焦点还给入口按钮。
10. 两张、三张切图均能直接打开完整横拼浮窗，在嵌入式预览内按 Esc 可关闭。
11. 点击遮罩可关闭浮窗，网页发送同名普通消息无法冒充扩展关闭消息。
12. 动态加入推文可出现按钮，复用推文节点后不会保留旧按钮。
13. 原图不可用时回退到 large，并展示质量说明。
14. 图片加载失败时提示失败序号，并禁止导出不完整图片。
15. 在浮窗内重新加载后可恢复预览。
16. 多次打开、关闭及重试均不增加浏览器标签页。
17. 拒绝非 X 图片服务器 URL。
18. 上述操作未出现未捕获的页面 JavaScript 异常。
19. 右转至 90°、180°、270° 后的尺寸和像素位置正确，连续右转四次后全部像素与初始图片一致。
20. 左转、切换布局及交换图片顺序后方向保持；还原方向可正确恢复未旋转的拼图。
21. 原始大小与适应窗口按旋转后的尺寸进行缩放。
22. 实际保存的旋转 PNG 为 180 × 960 像素；重新解码导出文件后，像素位置与预览一致，文件名带 `90deg`。

另外 5 项核心逻辑测试通过：URL 规范化；非法来源与重复图片拒绝；2～4 条竖切图横向拼接；奇数像素尺寸及过大画布限制；后台消息来源校验。
