## v1.5.0（2026-11-14，工作区候选版，未发布）

- 方案 A：合成图上限由「单边 30,000 像素 / 总 6,400 万像素」调整为「单边 65,535 像素 / 总 268,435,456 像素（约 2.68 亿）」。数值来自本机 Edge 157.0.4341.57 无头实测：16,384 × 16,384 可正常绘制并 `toBlob` 导出，16,384 × 16,385 与 320 M 像素时绘制静默失效（像素全透明但 canvas 尺寸不变），因此上限判断必须保留。
- 新增「等高横拼」：以所有图片中最高的一张为基准高度，其余按宽高比等比缩放到同一高度后横向拼接，边缘平齐、无留白；仅该模式开启高质量插值，原有横向 / 竖向 / 两列布局仍为零重采样像素级拼接。
- 静态检查：`core.js`、`viewer.js`、`background.js`、`content.js` 四个文件 `node --check` 全部通过。
- 几何与像素检查（无头 Edge 157，工作区副本）：27 项全部通过 —— 原有三布局回归、混合尺寸保留原尺寸与留白、等高模式基准高度 / 缩放宽度 / 单元格坐标、40,000 px 宽与 268,435,456 px 恰好允许、65,536 px 宽与 268,451,840 px 被拒、等高放大后超限被拒；真实 canvas 像素确认三色区域正确、上下边缘不透明。
- 端到端检查（无头 Edge 157，打桩 3 张不同尺寸原图，实际运行 `viewer.js`）：8 项全部通过 —— 初始横向 740 × 400 → 切换「等高横拼」1,933 × 400（三色块正确、底边无透明、保存按钮可用、状态提示正确）→ 切回横向恢复 740 × 400 且留白恢复。
- 未验证：登录后的 X 会话、Edge 常规窗口、真实 20 张大图；接近上限时的 PNG 导出耗时与内存峰值。
